# 自动化控制解调系统搭建

## 一、系统总体架构

本系统基于 PC 上位机软件实现对多台光电仪器的自动化协调控制，完成 FBG+MRR 温度传感器的定标与解调全流程。系统架构如图所示，主要由以下硬件和软件组成：

### 1.1 硬件组成

| 设备 | 型号/规格 | 功能 | 通信接口 |
|------|-----------|------|----------|
| 可调谐激光器 (TSL) | Santec TSL系列 | 提供 1500~1650nm 可调谐光源 | GPIB/USB |
| 相位调制器 (PM) | — | 将 VNA 射频信号调制到光载波上 | 射频输入 |
| 微环谐振器 (MRR) | 硅光芯片 | 波长选择性滤波，谐振峰随电压/波长移动 | Zynq DAC |
| 光环形器 (Circulator) | 三端口 | 将光信号导向 FBG 并收集反射光 | 无源器件 |
| 光纤布拉格光栅 (FBG) | λ_B ≈ 1551.85nm | 温度传感元件，反射特定波长 | 无源器件 |
| 掺铒光纤放大器 (EDFA) | — | 放大 MRR 输出的微弱光信号 | — |
| 光电探测器 (PD) | — | 将光信号转换为电信号 | 射频输出 |
| 矢量网络分析仪 (VNA) | 思仪 3671G | 测量 S21 传输参数（10MHz~30GHz） | GPIB |
| FPGA 电压控制器 (Zynq) | Zynq-7000 | 4通道 DAC 输出，控制 MRR 热光调谐电压 | 串口 (115200bps) |
| 上位机 (PC) | Windows | 运行控制软件，数据处理与显示 | — |

### 1.2 光路连接

```
TSL → PM → MRR (Zynq控制电压) → Circulator → FBG (温度传感)
                                      ↓ (反射光)
                                    EDFA → PD → VNA (S21测量)
```

**信号流向**：
1. TSL 输出窄线宽激光，经 PM 加载 VNA 射频调制信号；
2. 调制光进入 MRR，MRR 对特定频率产生谐振增强；
3. 光经环形器到达 FBG，FBG 反射其布拉格波长附近的光；
4. 反射光经环形器返回，通过 EDFA 放大后由 PD 检测；
5. PD 输出电信号返回 VNA，VNA 测量 S21 传输函数。

### 1.3 电控连接

```
PC ──GPIB──→ VNA (S21测量控制)
PC ──GPIB──→ TSL (波长/功率控制)
PC ──串口──→ Zynq FPGA (MRR电压控制, 4通道DAC)
```

        self.vna = self.rm.open_resource(self.resource_name)
        self.vna.timeout = 60000  # 60s 超时
    
    def setup_parameters(self):
        self.vna.write("*RST")
        self.vna.write(f":SENS:FREQ:STAR {start_freq}")

        self.vna.write(f":SENS:SWE:POIN {points}")
        self.vna.write(f":SOUR:POW {power}")

class LaserController:
    def connect(self):
        # 自动检测 GPIB/USB 接口上的 TSL 仪器
        get_address = GetAddress()
        get_address.initialize_instrument_addresses("GPIB", auto_select=True)
        tsl_instrument = get_address.get_tsl_address()
        self.tsl = TslInstrument(interface="GPIB", instrument=tsl_instrument)

    def set_wavelength(self, wavelength: float):

### 3.3 Zynq FPGA 电压控制器

通过串口 (115200bps) 与 Zynq FPGA 通信，控制 4 通道 DAC 输出：

```python
class ZynqVoltageController:
    def __init__(self, port='COM3', baudrate=115200, num_channels=4):
        self.serial = serial.Serial(port, baudrate, timeout=2)
    
    def set_voltages(self, voltages: list):
        # voltages: [V_ch1, V_ch2, V_ch3, V_ch4]，范围 0~10V
        for ch, v in enumerate(voltages):
            self._send_command(ch + 1, v)
    
    def _send_command(self, channel, voltage):
        # 发送 DAC 设置指令，格式: "CHx:voltage\n"
        cmd = f"CH{channel}:{voltage:.4f}\n"
        self.serial.write(cmd.encode())
```

电压控制用于：
- **定标阶段**：固定 MRR 电压为 V_ref = 1.25V
- **测量阶段**：扫描 MRR 电压（如 0.85~1.25V），寻找最佳匹配电压

## 五、数据处理与解调流水线

### 5.1 数据格式

**定标数据**（每个 Δλ 一个 CSV）：
```
Frequency_Hz,Magnitude_dB
10000000.0,-58.76
14998333.3,-65.72
...
```

**测量数据**（合并 CSV，多电压）：
```
Voltage,Frequency_Hz,Magnitude_dB
0.85,10000000.0,-61.95
0.85,14998333.3,-57.44
...
1.25,10000000.0,-54.37
...
```

### 5.2 解调流水线

定标流水线面板提供完整的四步操作流程：

1. **加载定标数据** → 读取 161 条 CSV，构建定标映射表
2. **加载测量数据** → 读取电压扫描 CSV，按电压分组
3. **执行匹配** → 归一化互相关匹配，输出 Δλ 和 ρ
4. **温度计算** → T = T₀ + Δλ/α

### 5.3 参数自动寻优

系统支持参数自动寻优功能：输入已知的目标 Δλ（如光谱仪测量值），自动搜索最佳的匹配带宽、候选数 K、平滑窗口组合，使匹配结果最接近目标值。

## 六、系统安全与可靠性设计

### 6.1 仪器安全

- **电压置零**：程序关闭时自动将所有 Zynq DAC 通道电压置零，防止器件损坏
- **超时保护**：VNA 通信超时 60 秒，避免程序挂死
- **异常恢复**：定标扫描支持暂停/恢复/中止，中止时自动恢复激光器波长

### 6.2 数据可靠性

- **实时保存**：每完成一个波长点立即保存 CSV，断电不丢失已采集数据
- **元数据记录**：保存完整的扫描参数（VNA 配置、波长列表、时间戳）
- **状态监控**：GUI 状态栏实时显示各仪器连接状态（绿/灰/红）

### 6.3 软件健壮性

- **多线程隔离**：仪器操作在 Worker 线程，GUI 始终响应
- **信号/槽通信**：线程间通过 Qt Signal/Slot 安全传递数据
- **配置持久化**：上次使用的定标目录自动保存，下次启动自动加载
